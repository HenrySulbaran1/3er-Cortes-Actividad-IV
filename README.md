# 🏦 Proyecto Final: Formulario Web de Captura y Portafolio Digital

Este repositorio consolida la entrega final de la asignatura, demostrando la capacidad de automatizar procesos administrativos mediante herramientas informáticas y la integración de tecnologías web.

## 🚀 Descripción del Proyecto
El sistema consiste en una interfaz web para la captura de datos de clientes y solicitudes de crédito. Cumple con los requerimientos de validación de datos en el lado del cliente (Frontend) y simula el registro de información en tiempo real mediante la manipulación del DOM, optimizando la experiencia del usuario.

Adicionalmente, se anexa el modelo de base de datos relacional diseñado en la etapa previa de la materia.

## 🛠️ Tecnologías y Herramientas Utilizadas
* **HTML5:** Estructura semántica del formulario web.
* **CSS3:** Maquetación y diseño responsivo integrado.
* **JavaScript (Vanilla):** Lógica de validación de datos, prevención de recargas y simulación de almacenamiento interactivo (despliegue de listas).
* **SQLite:** Esquema relacional de la base de datos de la Unidad 1.

## 📂 Contenido del Repositorio
1. `index.html`: Archivo principal que contiene la interfaz del formulario interactivo, estilos y scripts de validación.
2. `base_datos_unidad1.db`: Archivo consolidado con el modelo relacional y las tablas (`Clientes`, `Solicitudes_Credito`) trabajadas en la Unidad 1.

## ⚙️ Instrucciones de Ejecución
Este proyecto fue diseñado para ser portátil y de fácil acceso sin necesidad de configurar servidores locales complejos:

1. Descargar o clonar este repositorio.
2. Hacer doble clic sobre el archivo `index.html` para abrirlo en cualquier navegador web moderno (Chrome, Edge, Firefox).
3. Llenar los campos del formulario respetando las validaciones (monto mínimo, formato de correo, etc.) y procesar la solicitud para ver la interacción en pantalla.
